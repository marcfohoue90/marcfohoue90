# Marc Fohoue
**Aspiring Cloud & AI Engineer** · Master's in IT Systems Architecture @ Hénallux · Namur, Belgium

---

I'm learning Cloud and AI the hard way: by building real projects, breaking things, and figuring out why they broke.

My first real exposure came during my internship at **MIC Belgium**, where I worked with a team on a deepfake and document forgery detection tool. I deployed AI models on Azure and integrated them into the project. Later, at the **AI4GOOD hackathon**, my team built **CLARITY**, a RAG-based assistant for students — my first hands-on project with retrieval-augmented generation.

Most recently, I built **CertCoach** for the **Microsoft Agents League** hackathon: a multi-agent system on **Microsoft Foundry** that assesses certification readiness through multi-step reasoning. It earned the official **Reasoning Agents** badge (Microsoft Foundry · Agentic AI · Generative AI).

That journey changed how I think. I stopped copying code and started trying to understand the systems behind it.

Now I'm building real skills from the ground up — one certification, one project at a time.
